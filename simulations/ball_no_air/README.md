# Ball with no air

The first simulation: a ball launched with a starting speed and angle, with gravity
only. No air resistance.

- `mockup.html` — a preview of what the animation screen will look like. Double-click
  to open it in a browser. (Also online: https://claude.ai/artifact/HwkoejK6XQsR2gvnvN1cbo)
- `ball_no_air.py` — the simulation itself (coming next). Settings you can change are
  at the top of the file. Run it with `make run SIM=ball_no_air`.
- Design: `docs/superpowers/specs/2026-11-06-ball-no-air-design.md`
